# Intel Auctions Social

A WordPress plugin for intelauctions.com, the sister of the
[Intel Auctions Toolkit](https://github.com/SixGricks/IntelAuction). It turns each
auction into a set of Facebook posts, plans them three a day through OneUp, and keeps a
person in the loop on the posts that carry hard facts.

What it is built to do is set out in [`docs/build-spec.md`](docs/build-spec.md)
(DJ, Oct 12, 2026). It is built in phases, each shipped with publishing off and checked
before the next one starts.
